# Linear Regression From Scratch

An educational machine learning project focused on understanding and implementing linear regression using Python and NumPy.

## Objectives

- Understand the linear regression prediction equation.
- Implement predictions from scratch.
- Learn mean squared error as a loss function.
- Implement gradient descent to learn model parameters.
- Visualize predictions using Matplotlib.
- Evaluate predictions on sample data.

## Tech Stack

- Python
- NumPy
- Matplotlib

## Project Status

🚧 In progress — environment setup completed; implementation next.

## Learning Approach

The goal is to understand the mathematics behind the algorithm and implement the core training process without relying on a machine learning library to do it for us.
